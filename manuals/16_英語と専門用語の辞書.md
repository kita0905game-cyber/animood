# 英語が出てきたらここを見る
[目次へ](00_ここから読む.md)
画面の英語は見比べるために残しています。意味は右の日本語を読めば大丈夫です。画面更新で表記が少し変わる場合があります。

## ファイルや編集画面
| 英語・記号 | 意味・すること |
|---|---|
| File / Open | ファイル／開く |
| Save / Save as | 保存／名前を付けて保存。普段は保存を使う |
| Find / Replace | 検索／置き換え |
| Undo / Redo | 元に戻す／やり直す |
| Copy / Paste | コピー／貼り付け |
| Folder / Path | フォルダー／ファイルの住所 |
| Preview | 公開前の確認画面 |
| Reload / Refresh | 再読み込み |
| Read only | 読み取り専用。編集できない状態 |

## GitHub・Cloudflare
| 英語 | 日本語でいうと |
|---|---|
| Repository | サイトのファイルと変更履歴を保管する場所 |
| Code | ファイルを見る画面 |
| Branch / main | 作業を分ける枝／公開に使う主な枝 |
| Add file / Upload files | ファイル追加／アップロード |
| Choose your files | PCからファイルを選ぶ |
| Commit changes | 変更を履歴に保存する |
| Commit summary | 何を変更したかを書く短い説明。日本語でもよい |
| Pull request | まとめた変更を確認して主な枝へ入れるための画面 |
| Merge | 変更を合流させる。mainへの反映は公開につながる |
| Actions / Workflow | 自動処理／自動処理の手順 |
| Run workflow | 自動処理を今実行する |
| Deployment / Build | 公開処理／公開用ファイルの生成 |
| Success / Failed / In progress | 成功／失敗／実行中 |
| Revert | 過去の変更を打ち消す変更を作る |

## サイト編集に出る言葉
| 用語 | 意味 |
|---|---|
| HTML | 見出しや文章など、ページの構造 |
| CSS | 色、大きさ、配置の設定 |
| JavaScript / JS | クリックなどに応じて動かす処理 |
| JSON | データや設定を記録する形式 |
| id | 部品を特定する固有の名前 |
| class | 同じ見た目を使う部品につける名前 |
| data-i | AniMoodで翻訳を対応させる名前 |
| label | 表示する名前 |
| positive / negative | 加点側／減点側 |
| tags / weight | 特徴タグ／重み・点数 |
| hard filter | 該当した作品を順位に関係なく外す条件 |
| null | 情報がない状態。点数0とは違う |
| true / false | はい・有効／いいえ・無効 |
| function | 名前の付いた処理のまとまり |
| return | 処理の結果を返す |
| const / let | 値に名前を付ける宣言。通常の文章変更では残す |

英語の部品名は日本語へ置き換えません。たとえば `moodNames` を `気分の名前` にすると、他の処理とのつながりが切れます。説明は日本語コメント、画面の日本語は翻訳辞書へ書きます。
