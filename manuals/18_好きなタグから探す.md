# 好きなタグから探す方法を追加する
[見やすい入口へ](はじめに読む.html) ｜ [目次へ](00_ここから読む.md)

> これは **練習を兼ねた追加作業**です。公開前に必ずプレビューで確認します。初めてコードを変える場合は、先に[15 最初の練習](15_最初の練習を一緒に進める.md)を完了してください。

## 完成イメージ
「今夜の気分」「いつもの好み」「好きな作品から」に加えて、**好きなタグから**を選べるようにします。

例：

1. 「好きなタグから」を押す。
2. 「謎・考察」「アクション」のようなタグを最大3つ選ぶ。
3. 選んだタグを持つ作品が優先される。

この方法は、作品名を思い出せないときに便利です。作品の正式評価を追加する機能ではありません。

## 最初の練習で使うタグ
最初は次の6個だけを画面に出します。サイトの既存データで使っている**英語タグ名を一字も変えず**に使います。

| コード上の名前 | 日本語表示 | 意味 |
|---|---|---|
| `Mystery` | 謎・考察 | 謎解きや考察を楽しみたい |
| `Psychological` | 心理戦・頭脳戦 | 心理描写や駆け引きを見たい |
| `Action` | アクション | 戦闘や勢いを楽しみたい |
| `Emotional` | 感情を揺さぶられたい | 感動的な展開を見たい |
| `Comedy` | 笑いたい | コメディを見たい |
| `Cozy / Healing` | 癒されたい | 穏やかな時間を過ごしたい |

`Mystery` を `Mistery` のように打ち間違えると、候補が出ません。英語は画面に表示するためではなく、作品データとの照合に使う名前です。

## 1. 新しい探し方のボタンを追加する
編集するファイル：`index.html`

`data-mode="like"` を検索します。その行の**次の行**へ、これを追加します。

```html
<button data-mode="tags" data-i="modeTags">Pick favorite tags</button>
```

英語の意味は「好きなタグから選ぶ」です。ここでは英語の仮表示を置き、日本語は次の手順で用意します。

## 2. タグを選ぶ場所を追加する
同じ `index.html` で、`id="likePanel"` のまとまりを探します。そのまとまりが終わる `</div>` の直後に、次を追加します。

```html
<div id="tagPanel" hidden>
  <p class="eyebrow" data-i="tagLabel">PICK UP TO THREE TAGS</p>
  <p class="hint" data-i="tagHelp">Choose what you want to experience.</p>
  <div id="tagChoices" class="chips"></div>
</div>
```

`id` の3つ、`tagPanel`・`tagChoices`・`modeTags` は次のJavaScriptと同じつづりにします。

## 3. 日本語の文章を追加する
編集するファイル：`assets/app.js`

`const ja = {` を探します。`modeLike:` の近くに、次の3行を追加します。前の行にカンマがあることを確認します。

```javascript
modeTags: "好きなタグから",
tagLabel: "好きな要素を3つまで選ぶ",
tagHelp: "観たい体験に近いタグを選んでください。",
```

**保存してプレビュー確認：** 日本語モードで、新しいボタンが「好きなタグから」と出れば成功です。この時点ではボタンを押しても中身は出ません。それで正常です。

## 4. 選択肢の名前を用意する
同じ `assets/app.js` で、`const filterNames = {` のまとまりの直後に追加します。

```javascript
const directTagNames = {
  Mystery: ["Mystery", "謎・考察"],
  Psychological: ["Psychological", "心理戦・頭脳戦"],
  Action: ["Action", "アクション"],

  Comedy: ["Comedy", "笑いたい"],
  "Cozy / Healing": ["Cozy / Healing", "癒されたい"],

```

`["英語", "日本語"]` の順番です。ここで英語を変えないでください。

## 6. 画面にタグを表示する
`function renderControls() {` を探します。

### パネルを切り替える
次の行の下へ追加します。

```javascript
$("#likePanel").hidden = mode !== "like";
```

追加する行：

```javascript
$("#tagPanel").hidden = mode !== "tags";
```

### タグのボタンを作る
次の行の下へ追加します。

```javascript
chips("#filters", filterNames, filters, 4, () => {});
```

追加する行：

```javascript
chips("#tagChoices", directTagNames, tagChoices, 3, () => {});
```

**保存してプレビュー確認：** 「好きなタグから」を押し、6個の日本語ボタンが出るか確認します。3個選び、4個目を押すと最も古い選択が外れるのは既存の選択ボタンと同じ動きです。

## 7. 選んだタグを推薦ロジックへ渡す
`function profile() {` を探します。`const p = {` の中で、次の行の下へ追加します。

```javascript
shortOnly: $("#shortOnly").checked,
```

追加する行：

```javascript
directTags: mode === "tags" ? Object.fromEntries([...tagChoices].map((tag) => [tag, 3])) : {},
```

この `3` は「タグ1個の重み」です。後で強すぎる・弱すぎると感じたら調整できますが、練習では変えません。

## 8. タグで順位を付ける処理を追加する
編集するファイル：`assets/engine.js`

`let mood = 0,` を探し、最後の `like = 0;` を次のようにします。

```javascript
let mood = 0,
  tasteFit = 0,
  like = 0,
  direct = 0;
```

次に、`for (const [tag, w] of Object.entries(p.likeTags || {}))` のまとまりの**直後**に、これを追加します。

```javascript
for (const [tag, w] of Object.entries(p.directTags || {}))
  if (tags.has(tag)) {
    direct += w;
    hits.push({ tag, weight: w, kind: "direct" });
  }
```

次の条件を探します。

```javascript
if (!moods.length && !p.excludeId && tasteFit <= 0) return null;
```

次の1行に置き換えます。

```javascript
if (!moods.length && !p.excludeId && !Object.keys(p.directTags || {}).length && tasteFit <= 0) return null;
if (Object.keys(p.directTags || {}).length && direct <= 0) return null;
```

最後に、次の行を探します。

```javascript
const raw = mood * 3 + tasteFit * 2 + like * 3 + pace;
```

次に置き換えます。

```javascript
const raw = mood * 3 + tasteFit * 2 + like * 3 + direct * 3 + pace;
```

## タグを増やすとき
