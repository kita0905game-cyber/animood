# 見出し・文章・日本語を変更する
[目次へ](00_ここから読む.md)

> 初めて操作する場合：[色を変えて戻す練習](15_最初の練習を一緒に進める.md)から始められます。英語は[用語辞書](16_英語と専門用語の辞書.md)、貼る範囲や実行結果は[コピーと確認](17_コピーと確認の手順.md)を参照してください。


## 既存の大見出しを変更
編集するファイル：`index.html` と `assets/app.js`。
HTMLで `data-i="headline"` を探します。

変更前：
```html
<h1 data-i="headline">A mood. A reason.<br>Your next watch.</h1>
```
現在の意味は「気分と、好きな理由で。次の1本を。」です。
変更例：
```html
<h1 data-i="headline">What fits tonight?<br>Find your next anime.</h1>
```
日本語は「今夜の気分に合うのは？ 次に観るアニメを探そう。」です。
`app.js` の `const ja = ` 内で `headline:` を探し、その値だけを変更します。

```javascript
headline: '今夜の気分に合うのは？<br>次に観るアニメを探そう。',
```
現在は1項目ずつ改行してあります。`headline` から次の `intro` の手前までをよく確認し、隣の項目や区切りのカンマを消さないでください。

## なぜ2か所必要？
起動時にHTML内の英語を記憶し、日本語ボタンで `ja` の同名項目に差し替えます。`<br>` は改行です。
HTMLだけ直すと日本語表示では変化が見えないことがあります。

## 新しい文章を日英で追加
HTMLの表示したい場所に追加します。例は `hero` セクション内です。

```html
<p class="hint" data-i="welcomeNote">Start with one mood.</p>
```
意味は「まずは気分を1つ選んでみよう。」です。
`const ja = {...};` の最初の `{` のすぐ後に、次の項目を追加します。既存の項目は残します。

```javascript
welcomeNote: 'まずは気分を1つ選んでみよう。',
```
`welcomeNote` をHTMLと同じつづりにします。別の文章へ同じ名前を流用しません。

## JavaScriptで作られる文章の場合
結果カードの見出しなどは `app.js` の `t('Why it fits','合う理由')` のように両言語が並んでいます。この場合は同じ場所の2つを変更します。
作品タイトルはデータ内の英語名・日本語名を使用します。一般タグは現状、日本語表示でも英語のままです。

## 確認と戻し方
保存後に EN（英語）→日本語→EN の順で押し、どちらも意図した文章になるか確認します。
変化がなければ `data-i` と `ja` の名前を確認します。動かなくなったら変更した両ファイルをバックアップへ戻します。
見出しや紹介文を変更するときは[11](11_別ページを追加.md)のSEO生成上の注意も確認してください。
