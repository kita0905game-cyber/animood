# 避けたい条件を増やす
[目次へ](00_ここから読む.md)

> 初めて操作する場合：[色を変えて戻す練習](15_最初の練習を一緒に進める.md)から始められます。英語は[用語辞書](16_英語と専門用語の辞書.md)、貼る範囲や実行結果は[コピーと確認](17_コピーと確認の手順.md)を参照してください。

例：「ホラーを避ける」。編集：`assets/app.js`、`data/tag_scoring.json`。

## 1 名前を追加
`const filterNames = {` の直後へ追加：

```javascript
no_horror: ['No horror','ホラーを避ける'],
```

## 2 除外タグを追加
JSONの `"hard_filters": {` の直後へ追加：

```json
"no_horror": ["Horror"],
```
Horrorはホラーという既存タグです。この例では、そのタグが付いた作品を結果から外します。

## 3 選択上限を更新
既存は条件が4つなので、`chips("#filters", filterNames, filters, 4, () => {});` になっています。
5つ全部選べるようにするには次の部分へ置き換えます。

```javascript
chips('#filters',filterNames,filters,Object.keys(filterNames).length,()=>{});
```

## 4 確認
同じ気分で条件OFF／ONを比較し、ONの結果にHorrorタグがないことを確認します。
全条件を選んでも、前に選んだ条件が外れないか確認します。
タグ未登録の作品までホラーがないと保証する仕組みではありません。

## 話数の条件を変える場合
「12話以内」はJSONのタグ条件ではありません。
`assets/engine.js` の `a.episodes > 12` を変更し、HTMLの `data-i="shortOnly"` の英語、`app.js` の `shortOnly:` の日本語もそろえます。
話数が不明な作品を除外する部分 `!Number.isInteger(a.episodes)` は残します。

## 戻し方
追加した名前・JSON項目を外します。上限を動的にした部分は残しても元の4条件で機能します。
話数を変えた場合はロジックと日英の説明をすべて元に戻します。
