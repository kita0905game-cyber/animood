# 最初の練習：ボタンの色を変えて、元に戻す
[目次へ](00_ここから読む.md)

## この練習のゴール
自分でファイルを開く → 1つの値を変える → 保存する → 画面で確認する → 元に戻す、を体験します。
公開作業はしません。英語を自分で訳す必要もありません。
準備するものは、このPCとAniMoodの作業フォルダーです。すでに使えるエディター（文字やコードを編集するアプリ）を使います。

## 1 作業フォルダーを開く
キーボードの Windows キーを押しながら E を押します。ファイルを探す「エクスプローラー」が開きます。
上のアドレス欄をクリックし、次の1行をコピーして貼り付け、Enterを押します。「検索」欄ではなく、現在のフォルダー名が出ている欄です。

```text
C:\Users\裕生\.codex\.chatgpt-projects\g-p-6aa0d733473c8191beec3a637b3291ad\animood-canonical
```
成功の目印：`assets`、`data`、`manuals` と `index.html` が見えます。
`.html` などが見えない場合は拡張子（ファイルの種類を表す末尾）が非表示の可能性があります。`index` を別名にせず、そのまま扱います。

## 2 戻せるコピーを作る
`assets` を開き、`style.css` を1回クリックして選択 → Ctrl＋C。
1つ上の `animood-canonical` へ戻り、`.local` を開きます。
空いている場所で右クリック → 新規作成 → フォルダーで `練習前のコピー` を作り、その中でCtrl＋V。
成功の目印：コピー先に `style.css` があり、元の `assets` にも同じファイルがあります。移動ではなくコピーです。

## 3 編集用に開く
元の `assets/style.css` を右クリックし「プログラムから開く」で普段使うエディター、またはメモ帳を選びます。
コピー先のファイルを編集しないよう、開いている場所に `assets` が含まれるか確認します。
成功の目印：日本語コメントと `:root`、`--bg` などの文字が見えます。

## 4 変更する場所を探す
Ctrl＋Fを押し、検索欄へ `--accent` と入力します。
これは強調色の名前です。英語を覚える必要はありません。この文字をそのまま検索します。
現在の設定：

```css
--accent: #dbfa7b;
```
この行の色コード `#dbfa7b` だけを選択し、`#9ee7ff` に置き換えます。
変更後は次の1行です。

```css
--accent: #9ee7ff;
```
行の先頭の空白、`--accent:`、最後の `;` は残します。Ctrl＋Aでファイル全体を選択しません。

## 5 保存して見る
Ctrl＋Sで保存します。「名前を付けて保存」ではなく、今のファイルへ保存します。
[02 プレビュー](02_編集とプレビュー.md)を使って http://127.0.0.1:8767 を開きます。
成功の目印：診断ボタンや選択中の気分が黄緑から淡い水色になります。
公開サイトの `animood.pages.dev` を見ている場合は変わりません。ブラウザ上のアドレスを確認してください。

## 6 元に戻す
同じ設定の `#9ee7ff` を `#dbfa7b` へ戻し、Ctrl＋S。
成功の目印：プレビューのボタンが黄緑へ戻ります。ここまでできたら練習完了です。
途中でわからなくなった場合は、コピーしておいた `style.css` を元の `assets` へコピーして戻します。この練習以外の変更をしていないことを確認し、置き換えの確認が出たら対象が `style.css` であることを確認します。

## うまくいかなかったら
色が変わらない → 保存したか、元のファイルか、PCプレビューかを確認。
ファイルが `style.css.txt` になった → 保存形式がテキストになっています。バックアップへ戻し、元のファイルを開いてCtrl＋Sで編集します。
全体がおかしい → コピーしたファイルで戻してから、色コードだけを選び直します。
