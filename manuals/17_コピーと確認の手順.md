# コードを貼る場所・確認結果・戻し方
[目次へ](00_ここから読む.md)

## 「追加」は、既存のものを残して増やす
例：気分の名前を追加する場合。`app.js` を開きCtrl＋Fで `const moodNames` を検索します。
元は次のような並びです。これは先頭部分だけの抜粋です。

```javascript
const moodNames = {
  mind_bending: ["Mind-bending", "頭を使いたい"],
```
`const moodNames = {` の行末にカーソルを置き、Enterで1行作ります。その行に追加項目を貼ります。
完成した先頭部分：

```javascript
const moodNames = {
  adventurous: ["An adventure", "冒険したい"],
  mind_bending: ["Mind-bending", "頭を使いたい"],
```
この下の既存の気分と最後の `};` は残します。この例だけでファイル全体を置き換えません。推薦条件の追加は[06](06_気分を追加.md)も必要です。

## 「置き換え」は、指定された部分だけを交換する
「色コードだけ」なら `#dbfa7b` だけを選択します。「1行を置き換え」ならその行だけを選択します。
「まとまりを置き換え」は閉じ括弧まで確認が必要です。迷う場合は先にバックアップを取り、変更範囲を質問してください。
コード枠の上下に見える3つのバッククォートはマニュアルの表示用です。ファイルへ貼りません。

## 命令は1行ずつ実行する
[02](02_編集とプレビュー.md)の手順でPowerShellを開きます。以下はコードファイルへ貼るものではなく、PowerShellへ入力する命令です。
まず1行をコピー→貼り付け→Enter。終わるのを待って次へ進みます。

| 入力する1行 | 成功の目印 |
|---|---|
| `node --check assets/app.js` | エラーが出ず、次の入力待ちに戻る |
| `node --check assets/engine.js` | 同じくエラーが出ない |
| `python -m json.tool data/tag_scoring.json > $null` | エラーが出ない。成功時の表示は省略する命令 |
| `node --test tests/v05.test.mjs` | fail（失敗）が0。現在の既存テストは8件 |
| `python tools/build_site.py` | Built static site…（公開用サイトを生成しました）と出る |

`$null` は表示を捨てるPowerShellの指定で、設定ファイルを書き換える意味ではありません。
`node` や `python` が見つからないと出たら、サイトの書き間違いとは限りません。実行に必要なソフトがその画面から見えていない可能性があります。「この命令が見つからない」と伝えれば、PC環境の確認から進められます。

## 英語エラーの最初の見分け方
| 表示 | 意味・確認すること |
|---|---|
| Unexpected token | 想定外の記号。直前のカンマ・括弧・引用符を見る |
| Cannot read properties of null | 探した部品がない。HTMLのidを変えていないか確認 |
| Not found / 404 | ファイルやページが見つからない |
| Address already in use | 同じアドレスでプレビューが既に起動している可能性 |
| No such file | 命令を実行するフォルダーやファイル名が違う可能性 |
| Failed to fetch | データを読めない。プレビューの起動とアドレスを確認 |

## 保存と実行は違う
エディターのCtrl＋Sはファイルの保存です。PowerShellのEnterは命令を実行します。
プレビュー起動後に次の入力待ちへ戻らないのは正常です。起動し続けているためです。止めるときだけCtrl＋Cを押します。
