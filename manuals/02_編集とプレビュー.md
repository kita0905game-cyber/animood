# 編集を始める・プレビューを開く
[目次へ](00_ここから読む.md)

> 初めて操作する場合：[色を変えて戻す練習](15_最初の練習を一緒に進める.md)から始められます。英語は[用語辞書](16_英語と専門用語の辞書.md)、貼る範囲や実行結果は[コピーと確認](17_コピーと確認の手順.md)を参照してください。


## 編集するフォルダー
PCの作業場所は以下です。古い `animood` フォルダーと間違えず、`animood-canonical` を使います。

```text
C:\Users\裕生\.codex\.chatgpt-projects\g-p-6aa0d733473c8191beec3a637b3291ad\animood-canonical
```

HTMLをダブルクリックすると、編集ではなくブラウザ表示になる場合があります。コードエディターの「ファイルを開く」で `index.html` を選んでください。メモ帳でも編集できますが、括弧の色分けがあるエディターのほうが見やすくなります。
保存は Ctrl＋S、検索は Ctrl＋F、直前の操作を戻すのは Ctrl＋Z です。

## プレビュー
ブラウザで http://127.0.0.1:8767 を開きます。このアドレスは自分のPC用です。

> **大事：これは常に開けるリンクではありません。** 下の起動手順でプレビューを動かしている間だけ開けます。PCを再起動したあと、PowerShellを閉じたあと、スマホから開いたときは表示されません。公開サイトを見るときは https://animood.pages.dev/ を開きます。

開けなければ次の起動手順へ。PC再起動後はプレビューも再起動が必要です。

1. 上のフォルダーをエクスプローラーで開く。
2. アドレス欄へ `powershell` と入力しEnter。作業フォルダーで命令を実行する画面が開きます。
3. 次の1行を入力してEnter。

```powershell
python .local/live-preview.py
```

起動メッセージが出たら、ブラウザで同じアドレスを開きます。この画面は起動中のままにします。停止は Ctrl＋C。
「アドレスは既に使用中」と出たら、既にプレビューが動いていないかブラウザで確認します。

## 保存するとどうなる？
既存のHTML・CSS・JavaScript・公開データの保存後、おおむね1秒でページ全体が再読み込みされます。診断の一時的な選択が初期状態に戻ることがあります。
これは本番公開ではありません。

## 公開サイトと作品数が違うとき
公開サイトはGitHubの最新 `data/anime.json` を使い、PCプレビューはPCにある `data/anime.json` を使います。そのため、Airtable同期後にPCの作品数だけ古い場合があります。

1. まず、公開サイトとPCプレビューをそれぞれ再読み込みする。
2. それでも違う場合は、PCの `data/anime.json` が古い可能性がある。
3. 自分で編集している `index.html` や `assets` のファイルを上書きせず、**作品JSONだけ**をGitHubのmainから更新する。
4. 不安なら「PCプレビューを公開版の作品数にそろえて」と依頼する。

作品データはAirtableから作られる派生データです。作品数を合わせる作業と、HTMLやJavaScriptを公開する作業は別です。

## このプレビューの範囲
既存のトップページ用6ファイルだけを提供します。新しいファイルやSEOページは、そのままでは404になります。[11](11_別ページを追加.md)のビルド済みプレビューで確認してください。
`.local/live-preview.py` はこのPC用に準備した補助ファイルでGitHubにはありません。別PCへ移るときは再用意が必要です。

## 戻し方
編集前に `.local` に保存したファイルの中身を、元のファイルへ戻して保存します。
バックアップをサイト直下へ大量に置くより、`.local` 内に日付付きで置くと混ざりません。
