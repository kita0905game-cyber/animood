# 新しいページを追加する
[目次へ](00_ここから読む.md)

> 初めて操作する場合：[色を変えて戻す練習](15_最初の練習を一緒に進める.md)から始められます。英語は[用語辞書](16_英語と専門用語の辞書.md)、貼る範囲や実行結果は[コピーと確認](17_コピーと確認の手順.md)を参照してください。

トップ内の説明を増やすだけなら[05](05_ページの部品を追加.md)で十分です。URLを分けたいときにこの章を使います。

## 現在の仕組み
`tools/build_site.py` がトップと2つの案内ページを `.local/site` に生成します。
新しいHTMLを置くだけでは公開されません。公開するファイルの許可リストへ追加が必要です。

## 独立した説明ページを追加する例
1. リポジトリ直下に `about` フォルダーを作る。
2. 中へ `index.html` を作り、以下を保存する。

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>About AniMood</title>
  <link rel="stylesheet" href="/assets/style.css">
</head>
<body>
  <main>
    <h1>About AniMood</h1>
    <p>Find anime through the experience you want.</p>
    <a href="/">Back to AniMood</a>
  </main>
</body>
</html>
```
英語の意味は「AniMoodについて」「味わいたい体験からアニメを探す」「AniMoodへ戻る」です。
この独立ページには言語切り替えはありません。既存 `app.js` は診断用部品がある前提なので、このページへそのまま読み込ませません。
3. `tools/build_site.py` の `FILES = [` に `'about/index.html',` を追加する。
4. トップの適切な場所へ `<a href="/about/">About AniMood</a>` を追加する。日本語対応は[03](03_文章と言語.md)を参照。
5. 検索対象として公開するなら、同じPythonファイルの `urls = ...` の次へ `urls.append('https://animood.pages.dev/about/')` を追加する。

## 生成して確認
作業フォルダーのPowerShellで実行：

```powershell
python tools/build_site.py
python -m http.server 8768 --bind 127.0.0.1 --directory .local/site
```
http://127.0.0.1:8768/about/ を開きます。これはビルド済みの確認用で、自動更新はありません。
再編集後は別のPowerShellでビルドを再実行し、ブラウザを再読み込みします。サーバー停止はCtrl＋C。
新規HTML、トップのリンク、ビルド設定をまとめて公開します。
戻す場合は追加したリンク・許可リスト・サイトマップ追記を戻し、新規ファイルを外して再ビルドします。

## 既存SEOページの注意
現在の生成処理は、トップのタイトル・紹介メタ文を「元の文字列との完全一致」で置換しています。
トップの `<title>` や description を変更するときは、`build_site.py` の対応する `source.replace` / `html.replace` の検索文字列も合わせて変更します。
生成した各ページでタイトル・説明・canonical（検索エンジンへ伝える正式URL）がそれぞれ適切か確認します。作品数の固定表記も、データだけでは更新されません。
ページ数を増やすためだけの薄い説明を量産せず、そのページで役に立つ内容を用意します。
