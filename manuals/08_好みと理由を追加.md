# 好みの項目・好きな理由を増やす
[目次へ](00_ここから読む.md)

> 初めて操作する場合：[色を変えて戻す練習](15_最初の練習を一緒に進める.md)から始められます。英語は[用語辞書](16_英語と専門用語の辞書.md)、貼る範囲や実行結果は[コピーと確認](17_コピーと確認の手順.md)を参照してください。

気分とは別の機能です。「好み」は繰り返し使う興味、「好きな理由」は元作品のどこが好きだったかです。

## 好みに「人間関係」を追加する例
`assets/app.js` の `const tasteNames = {` の直後に追加：

```javascript
relationships: ['Relationships','人間関係'],
```
`data/tag_scoring.json` の `"taste_dimensions": {` の直後に追加：

```json
"relationships": {
  "label_ja": "人間関係",
  "tags": {"Friendship": 3, "Found Family": 3}
},
```
Friendshipは友情、Found Familyは血縁によらない家族的なつながりです。
好みのボタンと結果の特徴グラフの両方が増えます。
CSSの `.finger-grid` はPCで `repeat(9, 1fr)` なので、10軸を1行にしたければ `repeat(10, 1fr)` に変更します。スマホの `repeat(3, 1fr)` は別指定です。
確認：好みの新項目だけで診断、日英の名前、グラフ10軸、狭い画面の読みやすさ。

## 好みを選べる数を増やす場合
`chips("#tastes", tasteNames, taste, 3`、URLから読む `slice(0, 3)`、その次の保存済み好みを整える `slice(0, 3)` をそろえます。
HTMLと `ja` の `tasteLabel` の「3つ」も直します。

## 好きな理由に「人間関係」を追加する例
`app.js` の `const reasonDefs = {` の直後へ追加：

```javascript
relationships: {
  label: ['Relationships','人間関係'],
  tags: {'Friendship': 3, 'Found Family': 3}
},
```
この機能では、採点タグは `reasonDefs` にあります。`tag_scoring.json` への追記は不要です。
選んだ元作品にも同じタグがある場合だけ比較に使われます。元作品に記録がなければ「別の理由を選んでください」という案内になるのが正しい動作です。
確認：該当タグがある元作品で新しい理由を選ぶ／タグがない元作品で案内が出る／元作品自身が結果に出ない。

## 戻し方
追加した項目を対応する各ファイルから削除します。グラフの列数も変えたなら元の9へ戻します。
