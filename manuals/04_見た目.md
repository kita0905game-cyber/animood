# 色・文字サイズ・余白・スマホ表示を変える
[目次へ](00_ここから読む.md)

> 初めて操作する場合：[色を変えて戻す練習](15_最初の練習を一緒に進める.md)から始められます。英語は[用語辞書](16_英語と専門用語の辞書.md)、貼る範囲や実行結果は[コピーと確認](17_コピーと確認の手順.md)を参照してください。

編集：`assets/style.css`。まず変更する値を控えておきます。現在は設定ごとに改行し、日本語の区切りコメントを付けています。Ctrl＋Fで対象を探します。

## アクセント色を変える
探す目印：`--accent: #dbfa7b`。これは黄緑色です。
変更例：`--accent: #9ee7ff`（淡い水色）。この値だけを置き換えます。
ボタン、見出しの小文字、選択状態などに共通して反映されます。
`--bg` は背景、`--text` は本文、`--muted` は補助文字、`--line` は境界線です。
確認：選択中のボタンの文字が読めるか、背景と文字が見分けられるか。戻すときは元の色コードへ戻します。

## 紹介文の文字を大きくする
探す目印：`.sub`。
`21px` を `23px` に変えると通常画面の紹介文が大きくなります。
スマホには別の `font-size: 17px` があるので、そちらを `18px` に変えます。
`px` は大きさの単位です。まず1〜2ずつ変えると調整しやすくなります。

## 上の余白を減らす
探す目印：`.hero`。
`70px` が上、`0` が左右、`42px` が下です。上だけ減らす例は `padding: 50px 0 42px`。
スマホ側には `padding: 48px 0 25px` があるため、両方を確認します。

## 診断ボタンを丸くする
探す目印：`.cta`。その中の `border-radius: 5px` を `border-radius: 14px` に変えます。
他の部品にも `border-radius` があるので、一括置換はしません。

## 大見出しは3か所を見る
英語の通常画面：`.hero h1` の `clamp(46px, 7.5vw, 86px)`。
これは最小46、画面幅に応じた値、最大86という設定です。
日本語：`html[lang="ja"] .hero h1`。スマホ：`@media (max-width: 700px)` 内の `.hero h1`。
日本語指定は優先度が高いため、英語側だけ変えても日本語は同じサイズのままになる場合があります。

## スマホを確認
ブラウザの横幅を狭め、横スクロールが出ないか、ボタンが押せるか、長い日本語がはみ出さないかを確認します。
端末表示の機能があるブラウザなら幅390px前後も確認します。公開後は実際のスマホでも見ます。
変更前の値へ戻して保存すれば元に戻せます。
