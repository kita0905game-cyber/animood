# 気分の選択肢を1つ増やす
[目次へ](00_ここから読む.md)

> 初めて操作する場合：[色を変えて戻す練習](15_最初の練習を一緒に進める.md)から始められます。英語は[用語辞書](16_英語と専門用語の辞書.md)、貼る範囲や実行結果は[コピーと確認](17_コピーと確認の手順.md)を参照してください。

例：「冒険したい」を追加します。これは今後の編集例で、現在の正式設定ではありません。新しい推薦方針はルール文書にも記録します。
編集：`assets/app.js`、`data/tag_scoring.json`。HTMLにボタンを直接足す必要はありません。

## 1 表示名を追加
`const moodNames = {` を探し、最初の `{` の直後に追加：

```javascript
adventurous: ['An adventure','冒険したい'],
```
左の `adventurous` は内部の名前です。英語の意味は右側の日本語です。

## 2 採点表を追加
`tag_scoring.json` の `"moods": {` の直後に以下を追加します。ファイル全体は置き換えません。

```json
"adventurous": {
  "label_ja": "冒険したい",
  "positive": {"Adventure": 3, "Worldbuilding Heavy": 2},
  "negative": {}
},
```
このコード枠は、既存の項目の前へ入れる断片なので最後にカンマがあります。
Adventure（冒険）、Worldbuilding Heavy（世界観重視）は既存のタグです。つづり・空白・大文字を合わせます。
`label_ja` だけではボタン名は変わりません。画面の名前は `moodNames` が使われます。

## 3 確認
保存し、新しいボタンを選んで診断。結果の作品タグが採点表とつながっているか確認します。
ボタンだけ追加して採点表を忘れると、新しい気分単独では結果が出ません。
既存の2つまで選ぶ制限は自動で引き継がれます。

## 選択できる個数も増やす場合
`chips("#moods", moodNames, moods, 2` の2と、URL読み込みの `slice(0, 2)` の2をそろえます。
HTMLの `moodLabel` の英語と `ja` の日本語も「3つ」などに直します。個数を増やすと推薦も変わるので別作業として確認します。

## 戻し方・確認用命令
両ファイルに追加した `adventurous` の項目を外し、区切りのカンマを確認。
[12](12_確認と公開.md)の構文チェックと既存テストに加え、新しい選択肢で結果が出ることを手で確かめます。
