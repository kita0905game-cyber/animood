# 説明欄・リンク・ボタンを追加する
[目次へ](00_ここから読む.md)

> 初めて操作する場合：[色を変えて戻す練習](15_最初の練習を一緒に進める.md)から始められます。英語は[用語辞書](16_英語と専門用語の辞書.md)、貼る範囲や実行結果は[コピーと確認](17_コピーと確認の手順.md)を参照してください。


## 説明欄を1つ追加
編集：`index.html` と `assets/app.js`。
HTMLの `<section id="guide"` を探し、その直前に以下を追加します。既存のsectionの中へ紛れ込ませず、直前の `</section>` の後です。

```html
<section class="guide" id="howTo">
  <h2 data-i="howTitle">How to start</h2>
  <p data-i="howText">Choose a mood, then find your next watch.</p>
</section>
```
意味は「はじめ方」「気分を選んで、次に観る作品を探そう。」です。
`app.js` の `const ja = {` の直後に追加：

```javascript
howTitle: 'はじめ方',
howText: '気分を選んで、次に観る作品を探そう。',
```
既存の `guide` の見た目を再利用するためCSSの追加は不要です。
確認：説明欄が1つ増え、言語切り替えも動くこと。

## 説明欄へ移動するリンクを追加
先ほどの `id="howTo"` を使います。HTMLの表示したい場所へ追加：

```html
<a href="#howTo" data-i="howLink">How to start</a>
```
`ja` 内に `howLink: 'はじめ方を見る',` を追加します。
`#howTo` は同じページの目印です。クリックして説明欄へ移動すれば成功です。
別ページへ移動したいときは `href="/anime-recommendation-quiz/"` のように既存ページのアドレスを書きます。

## 押すと文章が出るボタンを追加
編集：同じ2ファイル。HTMLの表示したい場所へ追加：

```html
<button id="showHelp" class="text-button" data-i="helpButton">Show a tip</button>
<p id="helpText" class="hint" data-i="helpText" hidden>Try one mood first.</p>
```
`ja` 内に追加：

```javascript
helpButton: 'ヒントを表示',
helpText: 'まずは気分を1つ選んでみましょう。',
```
`app.js` の `$("#go").onclick = discover;` の直後に追加：

```javascript
$('#showHelp').onclick = () => {
  $('#helpText').hidden = false;
};
```
確認：最初はヒントが隠れ、ボタンで表示されること。日本語でも確認します。
ボタンを置くだけでは動作は増えません。移動だけならリンクが簡単です。
戻すときはHTML・翻訳・クリック処理の3か所をまとめて削除します。ボタンだけ消すとJavaScriptが存在しない部品を探してエラーになります。
